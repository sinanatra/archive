# dae

Static archive of projects made at Design Academy Eindhoven, previously hosted on IONOS.

- `thesis/` — Garbage In, Garbage out (was thesis.giacomonanni.info)
- `coco/` — In love with MS COCO (was coco.giacomonanni.info). Images converted from PNG to lossless WebP.
- `earth/` — Are from Earth (was earth.giacomonanni.info). Static version; the Python API is not included.
